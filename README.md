# Amimono Trend

YouTube の制作動画を軸に、編み物作品の名前と流行の変化を継続記録する GitHub Pages サイトです。Pinterest は使用しません。

## 公開方法
GitHub リポジトリの **Settings → Pages → Build and deployment** を開き、**Deploy from a branch**、**main**、**/(root)** を選択して保存します。公開後の想定URL: https://s1290025.github.io/Amimono_trend/

## 構成
- `index.html` — 外部ライブラリなしの静的サイト。レスポンシブな写真タイル、検索、地域・年・カテゴリー絞り込み、年別履歴、月別変遷表
- `data.js` — 作品と月ごとの観測記録。**毎月このファイルに追記して履歴を残す**
- `README.md` — この説明

## データを追加する
1. `data.js` の `items` に作品を追加。作品を識別するユニークな `id` を使います。重複した作品の別動画は、別の動画記録として区別してください。
2. `observations` に `{month:"2026-12",itemIds:[...],summary:"...",highlights:[...]}` を追加します。**これまでの月の配列は削除しません。**
3. GitHub にコミットすると、GitHub Pages が公開コンテンツを更新します。
4. 2027年になると、2026年の月次記録は自動的に「トレンド歴史表」で閲覧できます。2027年の新しい観測を追加すると「今年の変遷」に表示されます。

## 調査方針
- YouTubeの日本語、韓国語、英語の制作動画を優先する。
- サムネイルは作品に紐づいたYouTube動画IDから取得。タイルは同じ動画にリンク。
- `views` と `likes` は調査日に実際に確認できた数値だけ記録し、未確認は `null`。
- `evidence:"video"` は動画の詳細と反応を照合した記録、`evidence:"reference"` は再確認が必要な登録候補。
- 投稿されたことと「流行している」ことは別。複数の独立投稿者の反復出現、投稿増加、チャンネル平均との比較が確認できない場合は、流行確定と表示しない。
- `published` には確認できた正確な公開日だけを記録し、不明なら `null`。
- 作者やプラットフォームの権利を尊重し、動画サムネイルはリンク先の参照として表示します。画像ファイルはリポジトリにコピーしません。

## 制約
- YouTube Data APIキーやサーバーは使っていません。再生数・いいね数は**自動取得ではなく**収集時のスナップショットです。
- 毎月のデータ調査とGitHubへの追記は別工程です。このサイト自体はGitHub Pagesだけで自動収集するものではありません。
- 初期収録には動画IDを先行登録した「要再確認」候補も含みます。そのため初期件数は網羅的な人気順位を意味しません。
