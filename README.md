# Amimono Trend — 名前と形に出会う編み物図鑑

**目的は「まだ知らない、かわいい作品の名前と形を知ること」です。**
作品名がわかれば、利用者自身で作り方を検索できます。閲覧数だけの人気ランキングではありません。

公開サイト: https://s1290025.github.io/Amimono_trend/

## 調査・掲載方針

1. **発見を優先**する。最初から作品名を知っていることを前提にせず、帽子の付け足し、変形するブランケット、変わった髪飾り、バッグチャーム、フード付きスカーフなど形・用途・構造でも世界各地を調べる。
2. 情報発見は YouTube に限らない。Instagram、TikTok、Ravelry、ブランド・編み物専門メディア、現地語検索、ファッションの着用例を横断する。Pinterest は使用しない。
3. **掲載は実在する対応作品のYouTube動画1本と、動画のサムネイル**。写真だけが似た別作品で代用しない。動画未確認の流行は調査メモとして保持し、掲載しない。
4. 作品ごとに **日本語の名称、現地語・英語名、どんな形かが想像できる短い説明**、動画、投稿地域を記録。デザイナー固有の作品名（Sophie Scarf/Sophie Hood等）と一般的な形の名前（スカーフ/スクーディー等）を混同しない。
5. **定番とトレンドは両立する**。定番は長く作られている型。流行は、特定期間に注目・制作・検索などの増加が根拠付きで認められるもの。定番のニット帽でも、特定年の猫耳などの再注目があればその年にも掲載する。
6. **月別はその時期の発見・人気の証拠**、**年別はその年の広まりを複数の独立情報源から裏付ける**。動画の公開月=流行月、公開年=流行年とは扱わない。2026年1〜10月の遡及登録の一部は公開月ベースの候補であり、流行確定を意味しない。
7. 色・サイズ・作者・細かな装飾違いは原則同一 `groupId` にまとめ、タイルは一種類一つ。異なる機構の作品（バラクラバとキャップに後付けする耳当て、ソフィースカーフとソフィーフード等）を統合しない。動画記録は削除せず、確認済みの再生数が多いものを代表候補にする。
8. 作品ごとに発見情報源、地域、流行根拠、公開日、再生数・いいね数、確認日を可能な限り記録。数値未確認は `null`、流行判定が保留のものは候補として扱う。「注目された地域」と「投稿者の地域」を区別する。
9. 日本・韓国・英語圏に偏らず、インド、東南アジア、欧州、南米、アラビア語圏なども調べる。流行名のバリエーション、現地語の別名を追う。

## データと公開

- `index.html`: 月別トレンド、年別トレンド、作品図鑑（全作品・定番・流行した作品の切り替え）。名前・形・英語名で検索。動画のサムネイルからYouTubeを開く。
- `data.js`: `items` に元動画、`groupId` に作品の統合キー、`shape` に形の説明、`classic:true` に定番、`trendYears` に年別トレンド、`observations` に月別記録。
- `observations` は既存履歴を削除せず追記する。`trendYears` は動画の公開年ではなく流行した根拠がある年を指定する。
- GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root)。

YouTube Data API や自動クローラーはありません。再生数は調査時点の値であり、網羅的な年間ランキングではありません。
